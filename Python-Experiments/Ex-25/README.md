# Experiment 25 Ad Hoc Routing DSDV versus AODV

`omnetpp.ini` provides the MANET sweep template; `analyze_metrics.py` computes PDR, mean delay, and routing overhead from a CSV exported from actual runs. The Word report contains the configuration, analysis code, and manual's expected trends.

OMNeT++/INET are not available here, so no measured AODV/DSDV numbers are claimed.

Reference: ITA03 Mobile Computing Laboratory Manual, Experiment 25, pages 59-61.
