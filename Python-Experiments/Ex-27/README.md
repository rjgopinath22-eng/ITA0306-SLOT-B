# Experiment 27 Cellular Network Performance Evaluation

`omnetpp.ini` defines the Simu5G parameter study and `analyze.py` summarizes packet counts and delay from `.sca` scalar files. Run simulations first; then run `python analyze.py` in the project directory.

This workspace has no Simu5G/INET runtime or `.sca` results, so only the expected trend from the lab manual is reported.

Reference: ITA03 Mobile Computing Laboratory Manual, Experiment 27, pages 65-68.
