# Experiment 26 Capturing Simulation Traffic in Wireshark

`CaptureNet.ned` and `omnetpp.ini` define the client-router-server capture scenario. Run the simulation to create `results/capture.pcap`, then use the included filters/commands in Wireshark.

No capture was generated in this workspace because OMNeT++/INET and Wireshark/tshark are not installed. The Word report documents the setup and current run status.

Reference: ITA03 Mobile Computing Laboratory Manual, Experiment 26, pages 62-64.
