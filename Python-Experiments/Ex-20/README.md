# Experiment 20 CDMA Spreading and Despreading

Run `python experiment_20.py` to print user data, spread chip sequences, the composite signal, and despreading results. The program also creates `recovered_bits.csv` and `cdma_spreading.svg`. Requires NumPy (`pip install numpy`).

Reference: ITA03 Mobile Computing Laboratory Manual, Experiment 20, pages 45-48.
