# Experiment 22 Mobility and Handover in a Multi-Cell 5G LTE Network

`omnetpp.ini` contains the experiment settings to apply to a Simu5G multi-cell example. Module names may need adjustment for the installed Simu5G version.

The Word report includes the configuration and the manual's illustrative handover trace. This workspace does not contain `opp_run`, INET, or Simu5G, so the reference trace is not a locally generated simulation result.

Reference: ITA03 Mobile Computing Laboratory Manual, Experiment 22, pages 51-53.
